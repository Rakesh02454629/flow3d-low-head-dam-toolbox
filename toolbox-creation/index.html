Folder Organization¶

The HydroShare resource is organized into separate folders so that users can easily locate input data, geometry files, FLOW-3D model files, boundary conditions, results, and post-processing materials.

Flow3D_HydroShare_Toolbox/
│
├── README.md
├── lhd.png
├── 01_Input_Data/
├── 02_Geometry/
├── 03_FLOW3D_Model_Files/
├── 04_Boundary_Conditions/
├── 05_Step_by_Step_Walkthrough/
├── 06_Results/
├── 07_PostProcessing/
└── 08_Downloadable_Package/

Folder Descriptions¶

Folder / FileDescription
README.mdMain HydroShare landing-page description and link to the online toolbox.
lhd.pngRepresentative figure showing submerged-jump or reverse-roller behavior near a low-head dam.
01_Input_DataFlow rates, tailwater data, field observations, and other input data.
02_GeometryLow-head dam geometry, channel geometry, CAD files, STL files, or terrain surfaces.
03_FLOW3D_Model_FilesFLOW-3D HYDRO simulation files and model setup files.
04_Boundary_ConditionsInflow, downstream stage, rating curve, and boundary-condition summary files.
05_Step_by_Step_WalkthroughScreenshots and supporting notes for following the FLOW-3D setup workflow.
06_ResultsExample result figures, tables, plots, animations, and extracted model outputs.
07_PostProcessingOptional Jupyter Notebook, Python scripts, or post-processing files.
08_Downloadable_PackageComplete zipped toolbox package for download and reuse.
