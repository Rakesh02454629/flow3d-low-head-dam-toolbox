<h2>Downloadable Files</h2>

<p>
The following folders and supporting files are included in the HydroShare resource to help users set up, run, analyze, and interpret FLOW-3D simulations for low-head dam hydraulic hazard assessment. These resources provide the necessary input data, geometry, simulation files, boundary conditions, modeling instructions, and example results for investigating reverse roller formation and associated hydraulic hazards.
</p>

<h3>Using the Downloadable Resources</h3>

<p>
Users can download the available resources from HydroShare and follow the step-by-step instructions provided in this toolbox. The input data, geometry, and model files can be used to reproduce the example simulations, while the results and post-processing resources support the evaluation of hydraulic characteristics and reverse roller behavior under different flow conditions.
</p>

<p>
<strong>Note:</strong> FLOW-3D HYDRO software and an appropriate license are required to run the provided simulation files. Users should also verify the compatibility of the model files with their installed software version.
</p>
